# Mathematical uncertainty

- PDFs, photos and class notes can be incomplete, garbled or ambiguous. Transcribe what is there; mark doubtful tokens `[?]`.
- Never silently fill a missing step. Use the `> [!uncertain]` callout from `00-System/Conventions.md`, say what is missing, and label any bridge as `generated`.
- State assumptions (regularity conditions, i.i.d., parametrisation, one- vs two-sided) explicitly when a formula depends on them. If the source does not state them, say so.
- Check derivations you write: dimensions/units, limiting cases, a small numeric sanity check (run remotely if computing) where possible.
- When the source and your derivation disagree, report the disagreement; do not pick one silently.
