# Source integrity

- Never fabricate papers, authors, citations, DOIs, URLs, datasets, MIT resources or course material. If you cannot verify something, write `UNVERIFIED` and state what would verify it.
- Only cite a paper or URL that you retrieved and read in this session, or that the user supplied. Say which.
- Label each claim's origin with a source type from `00-System/Conventions.md`: `mit`, `primary-research`, `secondary`, `generated`, `user`. Generated exercises and explanations must never be presented as MIT or research content.
- Quote MIT/course material sparingly; paraphrase and give the location (unit, page, timestamp). Keep quotes short as a habit; content stays local, but the system is shared publicly.
- The course link in `memory.md` was supplied by the user; treat course structure (units, titles, dates) as unknown until ingested.
